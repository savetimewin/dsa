Arrays & Hashing Notes

Hashing
The general technique of using a hash function to store/find data quickly.
Hash function
Converts a value/key into a number.
Example idea: hash("cat") → 39281
Hash table
The underlying data structure that uses a hash function for fast lookup. Python set and dict are both implemented using hash tables.
Hash set
Stores values only.
Python: set()
Use when you only ask: "Have I seen this value before?"
Hash map
Stores key → value pairs.
Python: dict or {}
Use when you ask: "For this key, what value/info did I store?"
Dictionary
Python's name for a hash map.
Python: {}

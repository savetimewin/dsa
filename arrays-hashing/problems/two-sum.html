Time and Space Complexity

Interview-ready explanation for the hash map solution.
Time complexity: O(n)
Reason: 
for index, num in enumerate(nums):
This loop can visit each element in nums once.
Inside the loop: 
complement = target - num
Calculating the complement is O(1). 
if complement in hashmap:
Checking whether a key exists in a dict is O(1) on average. 
hashmap[num] = index
Saving a key-value pair in a dict is also O(1) on average.
So the total is: 
n elements × O(1) work per element = O(n)
Best case: O(1)
Example: 
nums = [2, 7, 11, 15], target = 9
It finds the answer at index 1 and returns immediately.
Worst case: O(n)
Example: 
nums = [3, 2, 4], target = 6
It may need to scan until a later element completes the pair.
Space complexity: O(n)
Reason: in the worst case, the hash map stores many previous numbers before the answer is found. The map can grow up to n entries.
Final answer:
Time:  O(n)
Space: O(n)

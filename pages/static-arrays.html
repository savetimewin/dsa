Static Arrays

Everything important in one page: what a static array is, how memory works, why indexing is O(1), why insert/delete can be O(n), how resizing works, common interview patterns, diagrams, and interactive visuals.

30-Second Recall
  • Static array = fixed-capacity, contiguous block of memory.
  • Fast at: arr[i] and overwrite by index.
  • Weak at: growing, middle insert/delete, shifting.
  • Key distinction: size = used slots, capacity = total slots.
Interview one-liner: Static arrays give O(1) direct access because elements are stored contiguously, but their fixed capacity makes growth expensive or impossible without allocating a bigger array and copying.

1. Core Idea

  • Fixed capacity: number of slots is chosen up front.
  • Contiguous: elements sit next to each other in memory.
  • Uniform size: address math works because each element has known size.
  • Ordered + indexed: position matters.

2. Strengths

  • O(1) random access
  • O(1) overwrite/update by index
  • Cache-friendly because memory is contiguous
  • Simple storage model

3. Weaknesses

  • Cannot truly grow in place when full
  • Middle insert/delete usually causes shifting
  • Unsorted search is O(n)
  • Off-by-one errors are common

Size vs Capacity

Capacity is fixed. Size changes until you fill all slots.

Quick Distinction

Size ≠ Capacity

Capacity

Total number of slots reserved in memory.

capacity = 5

Size

How many slots currently contain valid elements.

size = 3
A static array can have unused slots. Appending is easy only while there is still spare capacity.

Array Patterns in Interviews

  • Linear scan: max, min, sum, count
  • Overwrite / write pointer: remove or compact in-place
  • Two pointers: sorted arrays, opposite ends, merge, reverse
  • Prefix sums: fast range sum or left/right totals
  • Sliding window: longest / shortest contiguous segment

Common Pitfalls

  • Confusing size and capacity
  • Assuming append always works
  • Forgetting last valid index is size - 1
  • Mixing up direct access with search
  • Not accounting for shifting during insert/delete

Language Note

Python list behaves like a dynamic array, not a pure static array.

  • nums[i] is still O(1)
  • append() is amortized O(1)
  • insert(0, x) is O(n)
Interview questions often say “array” even if the language uses a dynamic array under the hood.

Minimal Pseudocode Examples

Linear scan

best = nums[0]
for x in nums:
    best = max(best, x)

Overwrite pattern

write = 0
for read in range(n):
    if keep(nums[read]):
        nums[write] = nums[read]
        write += 1

Prefix sum

prefix[0] = 0
for i in range(n):
    prefix[i + 1] = prefix[i] + nums[i]

How to Recognize an Array Problem

  • The input is an ordered list of values.
  • You care about positions or indices.
  • You are scanning left to right or right to left.
  • You may overwrite values in-place.
  • You need to compare neighboring or indexed elements.
An “array problem” does not automatically mean “use two pointers.” The actual solving pattern depends on the requirement.

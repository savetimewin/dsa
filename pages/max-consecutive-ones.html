Max Consecutive Ones

You are given a binary array nums, return the maximum number of consecutive 1's in the array.

Example 1:
Input: nums = [1,1,0,1,1,1]
Output: 3
Example 2:
Input: nums = [1,0,1,1,0,1]
Output: 2
Constraints:
  • 1 <= nums.length <= 100,000
  • nums[i] is either 0 or 1.
Python
class Solution:def findMaxConsecutiveOnes(self, nums: List[int]) -> int:current = 0best = 0for num in nums:if num == 1:current += 1best = max(best, current)else:current = 0return best

Insertion sort

Build a sorted left prefix. For each index i, take key = arr[i], compare left, shift larger values right, then insert key into its correct position.

for i in range(1, len(nums)):
    key = nums[i]
    j = i - 1
    while j >= 0 and nums[j] > key:
        nums[j + 1] = nums[j]
        j -= 1
    nums[j + 1] = key
